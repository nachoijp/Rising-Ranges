# Label fonts

The fonts Owlbear Rodeo draws an image's label in (see `src/vistazo/labelFonts.ts`), so the
Vistazo's labels read as the map's. Roboto, Permanent Marker, Dancing Script, Courier Prime and
EB Garamond come from Fontsource (npm, `@fontsource/*`), each with its own license there.

- `GoticaBastard.ttf` — Gotica Bastard, by Manfred Klein (2004), listed as "100% Free" at
  https://www.dafont.com/gotica-bastard.font
- `LemonTuesday.otf` — Lemon Tuesday, by Daria Kwon and Jovanny Lemonad (2016), SIL Open Font
  License 1.1 (`LemonTuesday-OFL.txt`), from https://www.dafont.com/lemon-tuesday.font
